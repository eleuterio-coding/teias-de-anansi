## 4. Medições independentes e workflow

O workflow da Etapa 2 usa permissões **contents: read**, sem publicar, sem tokens de escrita e sem comandos de Firebase deploy. Após a execução do contrato, roda a sequência completa de npm run check.

Também foram mantidas verificações independentes de Prettier, build e validação de recursos estáticos, condicionadas à instalação concluída, para permitir identificar esses resultados mesmo quando um teste anterior falhar. O passo temporário de extração do conteúdo formatado foi retirado após o commit consolidado.

A execução independente anterior [run #44814745844](https://github.com/eleuterio-coding/teias-de-anansi/actions/runs/44814745844) já havia comprovado build e validação de GitHub Pages, embora o check integrado ainda falhasse no Prettier. A execução #44815315020 confirmou **todos** esses controles em conjunto.
