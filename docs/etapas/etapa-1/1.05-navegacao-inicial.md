## Escopo realizado

2. Estrutura central de rotas em `src/app/routes.ts`.
3. Página inicial provisória em `src/app/pages/HomePage.tsx`.
4. Rotas de módulos com mensagens explícitas de **funcionalidade ainda não implementada** (biblioteca, personagens, campanhas, aventuras, NPCs, sessões, área do jogador e preferências).

6. `PageErrorBoundary` de renderização com recuperação simples e acesso ao início.

9. Testes automatizados de entrada, navegação, estado 404, erro e carregamento.

## Escolha de navegação

`HashRouter` usa URLs do formato `/#/biblioteca`. A escolha evita exigir fallback de servidor para que o navegador consiga retornar à rota, mas **não configura o endereço base do GitHub Pages, build, CI de deploy ou publicação**, todos reservados ao item 1.06. Os testes usam `MemoryRouter` para testar a navegação sem alterar o endereço real.
