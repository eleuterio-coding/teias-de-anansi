Caso contrário, a falta do lockfile será registrada como pendência.

## Execução no ambiente local

Requer Node.js >=20.19 e npm. Na raiz do projeto:

```bash
npm ci
npm run dev
npm run typecheck
npm run lint
npm run test:run
npm run format:check
npm run build
```

O comando `npm ci` requer `package-lock.json` versionado. Até esse arquivo ser gerado, é possível usar `npm install` para realizar a primeira instalação.
