## Como executar localmente

Requisitos: Node.js 22 recomendado (mínimo 20.19), npm, Git. Clonar ou mudar para a branch de fundação:

```bash
git checkout feature/etapa-1-fundacao-8-etapas
npm ci
npm run check
npm run preview
```

Abrir no navegador:

- `http://localhost:4173/teias-de-anansi/#/` — início provisório;
- `http://localhost:4173/teias-de-anansi/#/biblioteca` — Biblioteca, módulo reservado;
- `http://localhost:4173/teias-de-anansi/#/rota-inexistente` — página 404.

Para gerar uma prova local automatizada, com o Chrome/Chromium disponível e depois de compilar:

```bash
npm run proof:preview
```

O script abre um servidor temporário em `127.0.0.1:4173`, valida o `index.html`, verifica as respostas HTTP dos arquivos JS/CSS gerados, solicita que um navegador real processe três rotas e captura `inicio.png`, `biblioteca.png`, `nao-encontrada.png` e `relatorio.json` na pasta ignorada `proof/`. Encerra o servidor em seguida. **Não publica a aplicação.**

## Estrutura resumida

- `src/app`: bootstrap React, navegação e páginas provisórias;
- `src/layouts`, `src/components`, `src/styles`: fundação visual para a futura Etapa 2;
- `src/modules`: espaços reservados para módulos futuros;
- `src/services/firebase`: adaptadores preparatórios sem chamadas no bootstrap;
- `src/rules` e `src/data`: regras puras e dados **públicos** futuros;
- `tests`: testes isolados, inclusive simulação de Firebase;
- `scripts`: verificação de build, limites preventivos e prévia real;
- `docs`: histórico, limites de aprovação e manutenção.

## Limitações explícitas

1. Esta é uma prova de funcionamento da **fundação**, não uma homologação funcional do Hub: as páginas de RPG são placeholders.
2. A interface é provisória e **não representa a arte nem os componentes da Etapa 2**.
3. Não há login funcional, CRUD de banco, confirmação das cinco contas ou regras efetivamente testadas no Firebase.
4. A prova HTTP ocorre em servidor local do runner; não comprova disponibilidade do URL público.
5. Browser automatizado cobre três rotas; responsividade, acessibilidade completa e outros navegadores exigem verificações próprias.
6. As capturas e o build são artefatos temporários, retidos por sete dias, não equivalem a publicação.
7. A Etapa 2 não será iniciada automaticamente com a compilação; depende de aprovação explícita.
