## Configuracao publica versus segredos

Config publica do SDK Web (obrigatorios): `apiKey`, `authDomain`, `projectId`, `appId`. Opcionais: `messagingSenderId`, `storageBucket`. No Vite ficam sob prefixo `VITE_FIREBASE_*` quando fornecidos.

O Firebase confirma que o objeto `firebaseConfig` e identificador **nao secreto** do app Web; contudo, **qualquer campo `VITE_*` vai parar no bundle publicado**, portanto esse prefixo nao pode conter senhas ou chaves de servico administrativas. Consulte: https://firebase.google.com/docs/web/learn-more

- Nao versionar `.env.local`, `.env`, senhas, tokens, JSON de service account ou credenciais administrativas.
- `apiKey` do SDK Web **nao substitui autenticacao e regras Firestore**.
- O arquivo `.env.example` nao contem os valores reais de configuracao. O historico foi consultado somente para registrar a identidade do projeto.
- **Nao corrigir `teais-de-anansi` para `teias-de-anansi`** antes de confirmar a configuracao no console do projeto existente.
- Nao e necessario usuario fornecer dados ou entrar no Firebase Console para validar este item de preparacao.
