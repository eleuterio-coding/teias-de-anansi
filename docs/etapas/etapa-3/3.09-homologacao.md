## Requisito de homologação online — decisão de 22/11/2026

O Hub **deve funcionar e ser homologado 100% online**, diretamente no navegador de computador, tablet e smartphone. Os participantes **não devem instalar ferramentas de desenvolvimento nem executar `localhost`**. As instruções locais anteriormente sugeridas para o 3.09 **não correspondem ao requisito do projeto** e foram substituídas por este procedimento:

1. Disponibilizar uma **prévia Web HTTPS de acesso restrito**, separada da versão pública, a partir da branch de Etapa 3, **somente com aprovação específica para essa publicação de teste**.
2. Conferir hospedagem, barreira de acesso e compatibilidade com os domínios autorizados do Firebase Authentication; qualquer configuração remota necessária exige autorização à parte.
3. Cada titular entra **por conta própria** na URL da prévia, sem compartilhar senha ou token, e verifica login, papel, vínculos, rotas, refresh, leituras e logout.
4. Registrar apenas passou/falhou por critério, sem informações privadas. **Não confundir acesso autorizado à prévia com autorização para alterar Rules ou dados reais.**

**Não há prévia online criada ou publicada neste momento.** A homologação segue **parcial**, inclusive pelo problema já registrado das Rules históricas.
