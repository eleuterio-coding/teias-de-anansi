## Limitação do botão no GitHub Actions

O GitHub exige que o workflow de disparo manual esteja na branch padrão para exibir o botão Run workflow. Este arquivo está **somente na branch de desenvolvimento** e portanto **ainda não pode ser acionado pela interface**. É necessário revisar e adicionar um dispatcher mínimo seguro à branch padrão, ou promover o workflow controladamente, antes da ativação. A ação de adicionar o dispatcher NÃO deve disparar mudanças em Firebase ou publicação por si só.

O environment etapa-3-producao precisa permitir a execução manual; o GitHub Actions precisa ter acesso ao secret FIREBASE_SERVICE_ACCOUNT_TEIAS_DE_ANANSI e permissão contents:write para o push. Confirmar todas essas configurações antes do corte.

## Recuperação e segurança

- Falha antes do PATCH: nenhuma alteração em produção.
- Rules novas publicadas e falha no site: **NÃO** reverter para baseline excessivamente permissiva. Isolar acesso, diagnosticar e corrigir a interface ou manter página de manutenção autorizada.
- Falha de segurança após publicação: manter política restritiva e corrigir para frente com novos testes. Não reativar permissões antigas silenciosamente.
- O backup criptografado não pode ser recuperado sem a chave privada original. Guardar metadados da release anterior e SHA da main como evidência.
- Não há transação atômica entre Firebase e GitHub. Não declarar sucesso por simples execução dos comandos.
