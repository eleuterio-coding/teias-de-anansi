## Objetivo e escopo

Verificar as cinco identidades já existentes no **Firebase Authentication** e comparar, sem modificações, suas identidades reais com perfis `users/{uid}` e vínculos `memberships` no **Cloud Firestore**. O objetivo foi **inventariar e preservar**, não recriar ou corrigir automaticamente nenhum cadastro.

A auditoria usou exclusivamente a service account preexistente no GitHub Actions Secrets, com trocas de token OAuth e **requisições GET** de leitura a Firebase Auth e Firestore. O token não foi impresso, e nenhum UID, e-mail, senha, hash, ID de campanha, personagem, sessão ou aventura é apresentado nesta documentação.
