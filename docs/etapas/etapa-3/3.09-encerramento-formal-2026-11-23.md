## 2. Limpeza da branch de publicação

Os dois workflows do antigo procedimento de migração para Pages Actions, já desnecessários e incompatíveis com o método `legacy` aplicado, foram **removidos somente de `main`**:

- `.github/workflows/publicar-etapa-3-manual.yml` — removido no commit `427217eae14cf4e7bec6186b6691f45503f1ae76`.
- `.github/workflows/verificar-pages-preflight-manual.yml` — removido no commit `a577d44694a1f471308c17f2dd20f1766d68c798`.

Comparação entre a versão B publicada e a `main` após limpeza mostrou **somente os dois arquivos removidos**, sem alteração de `index.html`, JS/CSS, `.nojekyll` ou `README.md`. Nenhum workflow temporário de recuperação foi mantido na `main`.

O site permanece hospedado por GitHub Pages `legacy`. **Não modificar Settings → Pages** para Actions como parte de qualquer procedimento residual da Etapa 3.09; a origem de publicação está estabilizada em `main`/`/`. Um futuro pipeline de release deverá ser projetado explicitamente para a configuração adotada, sem ressuscitar o dispatcher A+B antigo.
